SETUP & HELP

Get FerryClip
connected.

FerryClip syncs clipboard text between a Windows PC and Android phone over the local network using TLS. Data transfers directly between paired devices; there is no cloud clipboard.

Current release: FerryClip v1.0.0. Windows installer and portable build are unsigned; the Android APK is signed with the project release key. See downloads.

Before you start

  • A Windows x64 PC and an Android phone.
  • Android 10 or newer for secure TLS 1.3 sync.
  • Both devices on the same reachable Wi-Fi, a phone/PC hotspot, or a VPN-routed LAN that permits local traffic. Internet access is not required for clipboard transfer.

Guest Wi-Fi isolation, firewall rules, or VPN policies can prevent the devices from reaching each other.

Install on both devices

Windows

  1. Download and run the Windows installer. The installer and portable build are currently unsigned, so SmartScreen may show an unknown-publisher warning. Select More info, then Run anyway if you choose to continue.
  2. Alternatively, download the portable ZIP and extract it.
  3. Open FerryClip from the notification area (system tray).
View Windows installer options

Android

  1. Download the release-signed APK to your phone and open it from Downloads. If upgrading from an earlier debug-signed build, uninstall that build first; uninstalling removes pairing and clipboard history.
  2. If Android asks, allow your browser or file manager to install unknown apps. You can turn that permission off after installation.
  3. Open FerryClip. Android may ask for notification and background-running permissions; manufacturer battery settings can affect reconnection.
View the Android welcome screen

Pair the devices

  1. Connect both devices to the same reachable local network.
  2. In the Windows tray app, select Generate code to connect.
  3. In FerryClip on Android, choose the add/pair PC action and enter the current six-digit code displayed by Windows.
  4. When the phone shows the PC as connected, pairing is complete. Pairing is initiated by you and the saved peer identity is checked on later connections.

If the automatic network route cannot reach your PC, use Android Advanced → Manual PC IP with an address reachable from that network. A common Windows hotspot address is 192.168.137.1, but network configuration can differ.

Only enter a fresh code shown by your own PC. Do not pair using an old screenshot or a code sent to you by someone else.

View the Android pairing walkthrough

Copy and send text

Windows → Android

While connected and sync is enabled, copy plain text on Windows. FerryClip transfers it to the unlocked phone; paste it in the app where you need it. Android may require you to unlock before the received text is applied.

Android → Windows

Copy plain text on the phone, then tap Send clipboard now in FerryClip’s notification or tap the Send to PC Quick Settings tile. Copying alone does not send. This deliberate action is required by Android’s clipboard access rules.

Add the Quick Settings tile (optional)

  1. In FerryClip, use the Add Send to PC shortcut action.
  2. If Android does not offer the add-tile prompt, open Quick Settings by swiping down twice, tap Edit or the pencil, find Send to PC, and drag it into the active tiles. Tap Done. The editor varies by phone.

You only add the tile once. The notification action remains an alternative.

View the Android notification and tile

Clipboard history is optional

When enabled, each device keeps its own encrypted history; clips are not shared between devices or uploaded to a FerryClip cloud service. Turn off saving or clear history in Settings; the guide below explains the platform-specific controls.

Settings that matter

Most controls are self-explanatory. These are the ones that change when FerryClip runs, what it saves, or how it sends text.

Windows

Start with Windows
Launch FerryClip at sign-in. Turn it on if you want it ready without opening it manually.
Close to tray
Closing the window keeps FerryClip running. Use Quit from the tray menu to exit; turn this off if you expect closing the window to stop the app.
Auto-copy received clips
Incoming phone text is placed on the PC clipboard automatically. Turn it off if you prefer to paste it yourself.
Pause syncing
Temporarily stops clipboard transfers without unpairing your devices.
Save clipboard history
Keeps encrypted history on this PC. Turn it off to stop saving new clips.
History limit & auto-delete
Set how many clips to keep and when older clips expire.
Clear history
Deletes saved clips; pinned clips are kept by the standard clear action.
Skip sensitive clips
Excludes recognized sensitive text from saved history only; it does not block a clipboard transfer.
View Windows settings

Android

Save history, limit & auto-delete
Control the clips stored on this phone and how long they are kept. History is separate from your PC.
Clear history
Deletes saved clips from this phone.
Skip sensitive clips
Skips Android-flagged passwords and one-time codes from history; it does not prevent sending a clip you choose to send.
Lock app
Requires your device fingerprint or PIN when you return to FerryClip.
Notifications & background activity
Notifications provide connection status and the send action. Battery restrictions can delay reconnecting while the screen is off.
Send to PC shortcut
Adds the Quick Settings tile for sending copied text with one tap. Set it up once; the notification action is an alternative.
View Android settings

Privacy and security

  • Clipboard transfer is direct between paired devices over the local network using mutually authenticated TLS 1.3 and pinned peer identities.
  • No account, internet relay, or cloud clipboard service is used for sync. Internet is needed for downloads and external links.
  • Phone-to-PC sending requires your explicit notification or tile action. FerryClip does not silently read Android clipboard changes in the background.
  • Only plain text is supported. Images, file transfer, iOS, and remote internet sync are not supported.
  • Android may display its own clipboard privacy indicator; FerryClip does not control system UI.

To check a file, run Get-FileHash -Algorithm SHA256 .\FerryClip-Windows-Setup.exe in PowerShell and compare its hash with the matching filename. Troubleshooting

Open the Windows tray menu

Select the FerryClip icon in the notification area, then right-click it for quick actions such as opening the app, pausing sync, or pairing a device.

View the Windows tray menu

Pairing stays on Waiting

Confirm both apps are running, both devices are on a reachable local network, and Windows Firewall allows FerryClip. Guest isolation or VPN policy may block local traffic. Generate a new code and try again.

A phone clip did not arrive on Windows

Unlock the phone, copy plain text, and tap Send to PC in the notification or tile. Check sync is not paused and that the clip was not skipped as sensitive.

Background reconnect is unreliable

Allow FerryClip notifications and background activity if Android requests it. Check the phone manufacturer’s battery controls. After a reboot, unlock the phone; if you force-stopped FerryClip in Android Settings, open it again manually.

Share diagnostics safely

On Android, use Advanced → Diagnostics → Share logs / Save to Downloads. On Windows, choose Open Log Folder from the tray menu. Include app versions, network type, and the action that failed. Do not share clipboard contents or sensitive log files publicly.

Code signing policy

The Windows binaries are currently unsigned. The project is applying for free code signing from SignPath Foundation and has not yet been approved. Author, Reviewer, and Approver: Tanishk Tewetia.

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it. Clipboard sync and local discovery communicate with the user’s paired devices on their local network; opening project/help links or downloading releases is initiated by the user outside the app’s sync traffic.

Uninstall

Uninstall the installer build from Windows Settings → Apps; the uninstaller asks whether to delete saved data, default No. Portable users must turn off Start with Windows before deleting the files. Data folders: %LOCALAPPDATA%\FerryClip and %APPDATA%\ClipSync, which can contain settings, pairing information, encrypted clipboard history, and logs. Uninstall Android as usual.
