SETUP & HELP

Get FerryClip
connected.

FerryClip transfers plain text between a Windows PC and Android phone on a reachable local network. Windows-to-phone is automatic; sending from Android requires a tap.

Current downloads: FerryClip 0.8.16 for Windows x64 and Android. These preview release builds are not production-signed: the Windows EXE is unsigned and the Android APK is debug-signed.

Before you start

  • A Windows x64 PC and an Android phone.
  • Android 10 or newer for secure TLS 1.3 sync.
  • Both devices on the same reachable Wi-Fi, a phone/PC hotspot, or a VPN-routed LAN that permits local traffic. Internet access is not required for clipboard transfer.

Guest Wi-Fi isolation, firewall rules, or VPN policies can prevent the devices from reaching each other.

Install on both devices

Windows

  1. Download the Windows x64 EXE below.
  2. Windows may warn that the publisher is unknown because the EXE is unsigned. Verify its SHA-256 checksum before running it.
  3. Quit an older FerryClip instance from its tray menu, then run the EXE. It is portable and includes its .NET runtime.
  4. Open FerryClip from the notification area (system tray).

Android

  1. Download the APK to your phone and open it from Downloads.
  2. If Android asks, allow your browser or file manager to install unknown apps. You can turn that permission off after installation.
  3. Open FerryClip. Android may ask for notification and background-running permissions; manufacturer battery settings can affect reconnection.

Pair the devices

  1. Connect both devices to the same reachable local network.
  2. In the Windows tray app, select Generate code to connect.
  3. In FerryClip on Android, choose the add/pair PC action and enter the current six-digit code displayed by Windows.
  4. When the phone shows the PC as connected, pairing is complete. Pairing is initiated by you and the saved peer identity is checked on later connections.

If the automatic network route cannot reach your PC, use Android Advanced → Manual PC IP with an address reachable from that network. A common Windows hotspot address is 192.168.137.1, but network configuration can differ.

Only enter a fresh code shown by your own PC. Do not pair using an old screenshot or a code sent to you by someone else.

Copy and send text

Windows → Android

While connected and sync is enabled, copy plain text on Windows. FerryClip transfers it to the unlocked phone; paste it in the app where you need it. Android may require you to unlock before the received text is applied.

Android → Windows

Copy plain text on the phone, then tap Send clipboard now in FerryClip’s notification or tap the Send to PC Quick Settings tile. Copying alone does not send. This deliberate action is required by Android’s clipboard access rules.

Add the Quick Settings tile (optional)

  1. In FerryClip, use the Add Send to PC shortcut action.
  2. If Android does not offer the add-tile prompt, open Quick Settings by swiping down twice, tap Edit or the pencil, find Send to PC, and drag it into the active tiles. Tap Done. The editor varies by phone.

You only add the tile once. The notification action remains an alternative.

Clipboard history is optional

FerryClip can save recent clips locally on each device. This is separate from sync: history does not go to a FerryClip cloud service and is not shared between your devices. Saved history is encrypted at rest (Windows uses current-user Windows data protection; Android uses a key held by Android Keystore).

  • History is enabled by default. Turn off Save clipboard history in Settings to stop saving new clips.
  • Set a limit (50, 100, or 500 clips) and retention (24 hours, 7 days, or no age-based expiry).
  • Skip recognized sensitive clips; sensitive content can still be saved if you change that setting. Android-flagged clipboard content is skipped by default.
  • Review, copy, pin, or delete saved clips in the app’s History view. Clearing history removes saved clips; Windows pinned clips are retained by the standard clear action.

Encryption at rest does not protect clips from someone using your already-unlocked account or device. Turn history off or clear it if you do not want clips retained locally.

Privacy and security

  • Clipboard transfer is direct between paired devices over the local network using mutually authenticated TLS 1.3 and pinned peer identities.
  • No account, internet relay, or cloud clipboard service is used for sync. Internet is needed for downloads and external links.
  • History is stored locally only when enabled, encrypted at rest, with controls for retention, limits, sensitive clips, and deletion.
  • Phone-to-PC sending requires your explicit notification or tile action. FerryClip does not silently read Android clipboard changes in the background.
  • Only plain text is supported. Images, file transfer, iOS, and remote internet sync are not supported.
  • Android can display its own clipboard privacy indicator. FerryClip cannot suppress operating-system UI.

Review the source and the release-specific checksums before installing unsigned preview builds. A checksum helps detect file changes; it does not independently verify who published the file.

Troubleshooting

Pairing stays on Waiting

Confirm both apps are running, both devices are on a reachable local network, and Windows Firewall allows FerryClip. Guest isolation or VPN policy may block local traffic. Generate a new code and try again.

A phone clip did not arrive on Windows

Unlock the phone, copy plain text, and tap Send to PC in the notification or tile. Check sync is not paused and that the clip was not skipped as sensitive.

Background reconnect is unreliable

Allow FerryClip notifications and background activity if Android requests it. Check the phone manufacturer’s battery controls. After a reboot, unlock the phone; if you force-stopped FerryClip in Android Settings, open it again manually.

Share diagnostics safely

On Android, use Advanced → Diagnostics → Share logs / Save to Downloads. On Windows, choose Open Log Folder from the tray menu. Include app versions, network type, and the action that failed. Do not share clipboard contents or sensitive log files publicly.
